Assignment 11 - Data-Driven Automation in Python Behave Framework

Objective:
Implement data-driven web automation using Python, Selenium and Behave BDD.

Application:
SauceDemo - https://www.saucedemo.com/

Concepts:
- Behave Scenario Outline
- Gherkin Examples table
- Multiple test-data combinations
- Selenium WebDriver
- Positive and negative login validation

Execution:
1. Open terminal in Source_Code.
2. Install dependencies:
   python -m pip install -r requirements.txt
3. Run:
   python -m behave

Test data is also documented in Test_Data/login_test_data.csv.
