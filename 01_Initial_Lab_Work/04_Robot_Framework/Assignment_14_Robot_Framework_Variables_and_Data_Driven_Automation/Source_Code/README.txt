Assignment 14 - Robot Framework Variables and Data-Driven Automation

Objective:
Use Robot Framework variables and execute the same login workflow with multiple
data sets stored in an external CSV file.

Application:
SauceDemo - https://www.saucedemo.com/

Concepts:
- Robot Framework variables
- DataDriver library
- External CSV test data
- Test Template
- Positive and negative test cases
- SeleniumLibrary
- IF/ELSE validation

Execution:
1. Open terminal in Source_Code.
2. Install dependencies:
   python -m pip install -r requirements.txt
3. Run:
   python -m robot variables.robot

Expected result:
4 tests passed, 0 failed.

Output files:
- output.xml
- log.html
- report.html
