Assignment 13 - Robot Framework Basic Syntax and Keywords

Objective:
Create a basic Robot Framework test case using SeleniumLibrary to open a browser, navigate to a URL, enter form data, click a button, and verify a web element.

Application:
SauceDemo - https://www.saucedemo.com/

Concepts:
- Robot Framework syntax
- Settings, Variables and Test Cases sections
- SeleniumLibrary
- Input Text
- Click Button
- Page Should Contain Element
- Wait Until Page Contains Element
- Suite Teardown

Execution:
1. Open terminal in Source_Code.
2. Install dependencies:
   python -m pip install -r requirements.txt
3. Run:
   python -m robot basic_syntax.robot

Expected result:
1 test, 1 passed, 0 failed.
