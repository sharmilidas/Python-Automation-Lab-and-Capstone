Assignment 06 – Windows, Tabs, and Iframes

Module:
Module 1 – Automation with Selenium

Websites used:
1. https://the-internet.herokuapp.com/iframe
2. https://the-internet.herokuapp.com/windows

What the script demonstrates:
- Switching into an iframe using switch_to.frame()
- Reading content inside the iframe
- Returning to the main document using switch_to.default_content()
- Opening a new browser window/tab
- Getting window handles using window_handles
- Switching between windows
- Reading the title of the new window
- Closing the new window
- Switching back to the original window
- Verifying the original page
